# Movie Recommendation System Using Decision Tree

## Project Description
This project is a Movie Recommendation System built using the Decision Tree algorithm.
The system recommends movies based on user preferences and input features.
The goal of this project is to understand how Decision Tree algorithms work in a
machine learning recommendation system.

## Algorithm Used
- Decision Tree Algorithm

## Tools & Technologies
- Python
- Google Colab
- VS Code (for local execution)
- Pandas
- NumPy
- Scikit-learn

## Dataset
A sample movie dataset is used containing features related to user preferences
and movie attributes.

## Project Workflow
1. Data loading and preprocessing
2. Feature selection
3. Training the Decision Tree model
4. Making movie recommendations
5. Evaluating the results

## Files Included
- Google Colab notebook (.ipynb)
- Python source code
- Dataset file (if applicable)
- PowerPoint presentation (PPT)

## How to Run the Project
1. Open the notebook in Google Colab or VS Code
2. Install required libraries
3. Run all the cells step by step
4. Enter user inputs to get movie recommendations
